# KhipuBot Frontend

Base de interfaz para el slice 001: React 19, TypeScript estricto, Vite, Tailwind, React Router, TanStack Query, Vitest y MSW.

## Desarrollo

1. Copiar `.env.example` a `.env`.
2. Ejecutar `npm install`.
3. Ejecutar `npm run dev`.

MSW está configurado para interceptar requests en las pruebas de Vitest. Las páginas de inicio, historial, monederos y ajustes son placeholders; autenticación y lógica de negocio aún no están implementadas.
